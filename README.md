## О проекте

TableBook - это современное одностраничное приложение (SPA) для онлайн-бронирования столиков в сети ресторанов. Сервис позволяет пользователям просматривать рестораны, фильтровать их по различным критериям, бронировать столики и сохранять понравившиеся заведения в избранное.

## Функционал

- Аутентификация - регистрация, вход, JWT-токены, защищённые маршруты
- Дашборд - последние добавленные рестораны и популярные бронирования
- Каталог ресторанов - поиск и фильтрация по кухне, вместимости столика, метро и времени работы
- Карточка ресторана - детальное описание, фотографии, часы работы, контакты, список столиков
- Бронирование столиков - выбор даты, времени, количества гостей (CRUD-операции)
- Избранное - сохранение понравившихся ресторанов
- Адаптивный дизайн - корректное отображение на всех устройствах
- Анимации - плавное появление карточек, переходы между страницами

## Локальный запуск

Клонирование репозитория:
git clone https://github.com/dzmb1k/restaurant-booking.git
cd restaurant-booking

Установка зависимостей:
npm install

Запуск в режиме разработки:
npm run dev

Сборка для продакшена:
npm run build
